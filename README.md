# Digital Flashcard System

A web-based Digital Flashcard System developed using Python and Flask as a 1st-semester mini project.

## Features

- Create digital flashcards
- Store questions and answers
- View saved flashcards
- Study and revise flashcards
- Form validation
- SQLite database integration

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- Flask-WTF
- SQLite
- HTML
- CSS

## Project Purpose

The application helps users create, store, and study digital flashcards, making learning and revision easier and more organized.
